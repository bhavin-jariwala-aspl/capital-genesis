# Administration

<!-- nav:top -->
> **[Docs roadmap](../README.md)** › **Administration** — CRM administrators
<!-- /nav:top -->

Concept guides for whoever administers a workspace: how configuration, permissions and automation fit together, and
which tool to reach for. The step-by-step screens are in the [Builder guide](../builder-guide/README.md); running the
platform itself is in [Platform operations](../platform-operations/README.md).

> **First time?** Read [Understanding Genesis](../understanding/README.md) steps 1–7 (about 2 hours).

Read in order. The first is the overview; the automation pair answers the most common question — "should this be a
workflow, an assignment rule, a score or an SLA?" — which is the most expensive one to get wrong.
