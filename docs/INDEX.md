# Genesis CRM — Knowledge Base

**The complete reference for Genesis CRM — for every role, every question.**

Genesis CRM is a metadata-driven, fully configurable CRM platform. Every module, form, field, pipeline, dashboard,
and workflow is defined in the database and rendered at runtime. No code changes needed to configure the system.

### Critical Developer Notes

- All UI components use **default exports** — `import Button from '...'`
- React Query v5: `useMutation` takes single options object, use `isPending` (not `isLoading`)
- Workflows are **fire-and-forget** — failures never block HTTP responses
- Always use `parseInt()` with bounds check for numeric IDs
- Tailwind JIT: use complete static class names, never assembled dynamic strings

## System Overview

### What Is Genesis CRM?

Genesis CRM is a **metadata-driven CRM platform** — every module, object, field, form, pipeline, dashboard, and
workflow is defined in the database. Administrators can reconfigure the entire data model from the browser without
touching code.

**Current status**: v3.2.0 — 8.2/10 against industry CRM leaders,
9.5/10 as configurable internal CRM, with end-to-end inter-module connectivity.
The insurance domain (quotes, applications, underwriting, policies, claims,
commissions) was removed on 2026-10-13.
