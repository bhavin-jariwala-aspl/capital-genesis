## Builder & Configuration Guides (Admins)

These step-by-step guides explain how to configure Genesis CRM from scratch
using the **Builder** section of the app. They are aimed at administrators — no
coding required. The Builder appears in the left sidebar only for **Admin** and
**Super Admin** roles. If you are setting up a new workspace, work through them
roughly in the order below.

### Configure — model your data and screens

- [1. Modules & Objects](01-modules-and-objects.md) — define what data you store
- [21. Appearance & Branding](21-appearance.md) — brand colours, shape, density, typeface, dark mode and chart palette for everyone
- [2. Form Builder](02-form-builder.md) — design the create/edit screens, field look, and validations enforced on save
- [3. Dashboard Builder](03-dashboard-builder.md) — build charts and KPI views from live data
- [4. Pipeline Builder](04-pipeline-builder.md) — set up Kanban stages
- [5. Wizards](05-wizards.md) — create guided, multi-step entry flows

### Automate — let the system act for you

- [6. Workflows](06-workflows.md) — trigger actions on events
- [7. Assignment Rules](07-assignment-rules.md) — auto-assign records to people
- [8. Lead Scoring Rules](08-lead-scoring-rules.md) — score and grade leads
- [18. SLA Engine](18-sla-engine.md) — response/resolution targets, escalations & the live SLA board
- [19. Reports](19-reports.md) — build, share and schedule your own reports with no technical help; includes a suggested on-site training run
- [20. Document Management](20-document-management.md) — files, folders, in-document search, tracked sharing, templates & e-signature

### Connect — talk to the outside world

- [9. Integrations](09-integrations.md) — connect external services
- [10. Integration Health](10-integration-health.md) — monitor those connections
- [11. Email Templates](11-email-templates.md) — reusable, personalized emails
- [12. Social Media](12-social-media.md) — scheduled posts, campaigns, and the inbox of mentions routed to you
- [13. Push Notifications](13-push-notifications.md) — broadcast in-app alerts

### Manage — people and access

- [14. Permissions](14-permissions.md) — control what each role can see and edit
- [15. Employees](15-employees.md) — add and manage users
- [16. Roles & Levels](16-roles-and-levels.md) — define the access hierarchy
- [17. Org Chart](17-org-chart.md) — explore the whole reporting hierarchy interactively
